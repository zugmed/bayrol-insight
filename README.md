# Bayrol Insight

A lightweight, open-source telemetry and monitoring tool for Bayrol Automatic SALT systems.

## Philosophy

Simple first. Clever later.

The goal of this project is to understand and document the Bayrol protocol while providing useful monitoring tools.

## Roadmap

### v0.1
- [ ] Connect to the Bayrol MQTT broker
- [ ] Receive telemetry
- [ ] Decode first variables

### Future
- Historical logging
- Grafana dashboard
- Smart recommendations
